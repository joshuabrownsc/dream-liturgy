PUT YOUR WEBFONT FILES IN THIS FOLDER.

The page looks for these exact filenames:

  DreamAvenue.woff2        DreamAvenue.woff
  TTDrugs-Regular.woff2    TTDrugs-Regular.woff
  TTDrugs-Medium.woff2     TTDrugs-Medium.woff
  TTDrugs-Bold.woff2       TTDrugs-Bold.woff

If a file is missing, nothing breaks. The page falls back to a
close substitute automatically.

One important note. Desktop font files (.otf / .ttf) are licensed
for print and design software, not for embedding on a website.
You need a WEBFONT license for each family, which gets you the
.woff2 files above:

  Dream Avenue  - Alit Design. Free for personal use only.
                  A commercial or web license must be purchased.
  TT Drugs      - TypeType. Buy the web license at typetype.org.

Have both files converted to .woff2 by whoever supplies them, or
use a converter, then drop them here and push. No code changes.
